clip-channels

Privacy Policy

Effective date: 19 November 2026

Who this covers

clip-channels is a private tool used only by its owner, on the owner's own YouTube channels (Kept Faith, Front Row Bits and Talking Stage Clips). The only Google accounts that sign in to it are the owner's. It is not offered to anyone else.

YouTube API Services

clip-channels uses YouTube API Services: the YouTube Data API v3 and the YouTube Analytics API. By using it you agree to the YouTube Terms of Service. Google's handling of your data is described in the Google Privacy Policy.

What it accesses

When the owner signs in with Google, clip-channels asks for two permissions (OAuth scopes), and uses them only on the owner's own channels:

  • https://www.googleapis.com/auth/youtube.force-ssl: to read channel, video and comment data, and to post replies to comments on the owner's own videos.
  • https://www.googleapis.com/auth/yt-analytics.readonly: to read YouTube Analytics reports (such as views, watch time and subscribers gained) for the owner's own channels.

It does not ask for or store any YouTube or Google password.

How the data is used

  • Channel and video statistics are read to measure how the owner's channels and videos perform.
  • Comments on the owner's videos are read so the owner can reply, and replies are posted as the owner's channel.

The data is used for nothing else. It is not used for advertising, it is not sold, and it is not shared with or transferred to anyone. Only the owner sees it.

Where the data is kept

  • Everything clip-channels obtains, including the sign-in token Google issues, is kept only on the owner's own computer. There is no server and no database operated by clip-channels.
  • Data is sent only between the owner's computer and Google's APIs, over encrypted HTTPS connections.
  • Stored comment and channel data is deleted or refreshed within 30 days. Stored analytics may be kept longer, and in that case authorization is checked again at least every 30 days.

Cookies, ads and third parties

clip-channels does not use cookies or similar tracking, shows no ads, and lets no third party serve content through it or collect information through it. This website is a static page hosted on GitHub Pages. GitHub may log visitors' IP addresses for security, as described in the GitHub General Privacy Statement.

Google API Services User Data Policy

clip-channels' use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including its Limited Use requirements, and to the YouTube API Services Developer Policies.

Revoking access and deleting data

  • You can revoke clip-channels' access to your Google account at any time at https://myaccount.google.com/permissions (Google security settings). This is in addition to the deletion below.
  • After access is revoked, all data clip-channels obtained under that permission is deleted from the owner's computer within 7 days.
  • You can ask for stored data to be deleted at any time by writing to the contact address below; it is deleted within 7 days. Deleting data stored by clip-channels does not delete anything stored by YouTube. To delete data on YouTube itself, use YouTube.

Changes

If this policy changes, the new version is posted on this page with a new effective date. Data is never used in a new way without first updating this policy.

clip-channels

clip-channels is a private tool used only by its owner. It uses YouTube API Services to read analytics for, and reply to comments on, the owner's own YouTube channels: Kept Faith, Front Row Bits and Talking Stage Clips. It is not offered to the public, and it does not access any other person's account or channel.

What it does, on the owner's channels only:

  • Reads channel and video statistics (views, watch time, subscribers) from the YouTube Analytics API and the YouTube Data API v3.
  • Reads comments on the owner's own videos and posts replies to them as the owner's channel.

By using clip-channels you agree to be bound by the YouTube Terms of Service. How the tool handles data is set out in the Privacy Policy.
